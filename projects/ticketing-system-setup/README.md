# Ticketing System Setup

## Overview

This project documents a basic help desk ticketing workflow using Jira Service Management Free.

## Goal

Set up a simple support queue and use it to document realistic help desk troubleshooting tickets.

## Planned Ticket Lifecycle

1. Request submitted
2. Ticket triaged
3. Category and priority assigned
4. Troubleshooting notes added
5. Ticket resolved
6. Ticket closed

Screenshots will be added as the workflow is completed.
