# Active Directory Regional Structure

This was one of my Active Directory homelab projects. I built out a simulated Asia region structure so I could practice organizing users, groups, computers, and servers in Active Directory.

## What I Practiced

- Creating a clean AD structure.
- Organizing users and groups.
- Separating users, computers, and servers.
- Thinking through naming conventions.
- Understanding how OUs can help with administration and future policies.

## What I Learned

This helped me understand how AD can be organized before support work starts. If a user needs a password reset, group access, or troubleshooting, the structure makes it easier to know where accounts and resources belong.
